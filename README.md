# Custom WordPress Stable Build

This repository is an automated downstream mirror and build of WordPress Stable, combined with customized midstream components and configurations.

## Source Repository
The primary pipeline and source tracking for this build is maintained internally at:
[https://labs.wsad.io/wsad-io-technologies/public/forks/wordpress-automation/wordpress-stable-tracking](https://labs.wsad.io/wsad-io-technologies/public/forks/wordpress-automation/wordpress-stable-tracking)

## About
This automated build pipeline regularly synchronizes with official WordPress stable releases, overlays custom midstream layers, runs security vulnerability scans and secret detection checks, and pushes the final hardened distribution here.
